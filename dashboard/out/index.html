Final-year research project · simulation study

Can a learned policy allocate hospital beds better than rules and optimisation?

NeuroTwin is a validated discrete-event digital twin of an emergency department, two specialty wards and an ICU. It compares an in-house PPO agent with tuned rules and an exactly solved optimiser, under normal load and under stress the agent never saw in training, using pre-registered statistics over 2,500 test episodes.

Honest evaluation

Protocol committed before the test run

50 untouched test seeds, hierarchical paired bootstrap over 5 agents, Holm correction over 100 comparisons. One amendment, disclosed.

A failure mode rules don't have

1 of 5 agents collapsed in 2% of stress runs

Out-of-distribution states made one agent hold patients while beds emptied. No rule-based policy ever collapsed, a key robustness finding.
